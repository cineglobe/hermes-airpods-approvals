# Demo plan (under 90 seconds)

Everything shown is real: a real Hermes agent, real AirPods, real approvals. No staged audio or edited outcomes. Record the AirPods audio separately so viewers can hear what you hear, and say so on screen.

| Time | Shot | Sound |
| --- | --- | --- |
| 0–8s | Person away from the desk with AirPods in, the agent working on the Mac behind them. Title: "Your agent needs a yes." | Room sound |
| 8–20s | Screen: the agent reaches a real command needing approval. | Chime, then the request read aloud |
| 20–32s | Close on the head. A shake: three taps, left and right. | Taps, then the deny sound |
| 32–40s | Screen: Hermes shows it was denied. | |
| 40–58s | A second request. A nod: three taps from above and below. | Taps, then the confirm sound |
| 58–66s | Screen: the command runs. | |
| 66–78s | A slow head turn and a glance: taps but no answer. The prompt is still on screen. Caption: "Everyday movement answers nothing." | |
| 78–88s | Settings page and the repo name. | |

## Setup

- Use a harmless command that really needs approval, in a scratch folder.
- Practise with **Try it** first.
- Pick the voice before recording. Read [the README](../README.md#the-voice).

## Submission

1. Push the public repository.
2. Put the commit SHA and screenshots into `upstream/catalog-entry.yaml`.
3. Run `hermes plugins validate` at that commit.
4. Open the catalog PR from a new branch on the `cineglobe/hermes-agent` fork.
5. Post the video on X, tagging the Nous Research account.
6. Send both links through the entry form before 5PM EST on 11 Nov 2026.
